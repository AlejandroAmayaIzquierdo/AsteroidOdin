## Description

**AsteroidOdin** is a project I challenged myself to build in order to overcome the insecurities I had developed from writing code with AI all day.

I challenged myself to create a project entirely using my own knowledge, researching and learning the old-school way through the internet. I have to say that my math skills could be better, but I managed to relearn a few things about trigonometry and arithmetic. On top of that, the challenge of learning Odin was enough to keep me motivated throughout the development of this project.

I don't intend to publish or improve this project. It's simply a personal challenge to keep learning new things and, hopefully, start exploring more low-level programming to better understand how programs communicate with the system.

I encourage everyone to keep learning new things and avoid becoming a proxy meat for AI. I believe AI is a new tool that we need to start incorporating into our work, but if we stop learning new things and improving ourselves, we'll eventually end up accepting whatever AI suggests as if it were religious scripture.
